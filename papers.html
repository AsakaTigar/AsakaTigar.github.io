PAPER · 01 ICMR 2026 第一作者 多模态 / 语音合成

ATRIE：面向角色驱动语音合成的鲁棒推理与情感自适应调优 ATRIE: Adaptive Tuning for Robust Inference and Emotion in Persona-Driven Speech Synthesis

研究背景

当下的 TTS（文本转语音）系统在"声音像不像角色"和"情感对不对"这两件事上仍然薄弱：要么使用统一中性嗓音，要么虽然能给出情感强度，但不知道为什么要在这一句生气、那一句温柔。

对动漫角色扮演（Role-Play）这种重度依赖角色一致性的应用而言，没有可解释的情感来源，意味着配音"飘忽"、人设易崩。

核心动机

能不能让模型先像演员那样"在心里讲一遍角色为什么这样说话"，再把这份理由翻译成韵律控制信号，从而在保持角色一致的前提下，做到细粒度、可实时的情感语音？

方法 · 离线蒸馏 + 在线推理的两阶段解耦范式

填补的研究缺口

现有表达性 TTS 走两条死胡同：第一条是在线挂载 LLM，让大模型实时给出情感推理，效果好但延迟动辄秒级，根本无法支撑实时对话或游戏配音；第二条是预设情感标签（happy/sad/angry），灵活性差，无法解释"为什么此处要愤怒"，遇到细腻情绪就崩。两条路径都没能同时满足"细粒度可解释"与"实时可部署"。

提出的新范式

把 LLM 的情感推理能力编译成静态信号：训练阶段一次性让 LLM 跑完所有台词，输出完整的情感推理链；再用蒸馏把这条链压缩到一个 3 维连续 VAD（Valence 愉悦度 / Arousal 唤醒度 / Dominance 支配感）韵律目标。推理时只跑一个轻量 MLP Adapter，彻底切断对 LLM 的运行时依赖，把"重推理"留在训练，把"轻映射"留给在线。

创新模块逐一拆解

① LLM Rationale Generator (Qwen2.5-14B)离线阶段用 Qwen2.5-14B 作 teacher，针对每句台词生成一段思维链(CoT)情感推理，并输出结构化 JSON（含 VAD 分数 + 相对韵律标量）。为什么需要它？没有显式推理链，模型学到的情感是黑盒映射，遇到反讽、克制等复杂情绪会失败；显式 rationale 等于给学生模型提供"老师的解题步骤"。推理链再经冻结的 Sentence-BERT 编成 768 维语义向量 h 用于对齐。
② VAD 三维韵律目标把推理链落到 3 维连续 (Valence 愉悦度 / Arousal 唤醒度 / Dominance 支配感) + 相对韵律标量。为什么是 VAD 连续空间而非离散标签？VAD 是心理学公认的情感空间基底，可连续插值（如"半愤怒-半悲伤"），维度低、训练易收敛、迁移到任何韵律控制器只需线性投影。
③ P2P · Persona-to-Prosody Adapter学生模型，11.8M 参数、4 层 Transformer、hidden 512、8 头，含 Cross-Attention + 4 个并行韵律预测头（Pitch/Energy/Duration/Pause）。把 VAD 映射成韵律控制信号注入 GPT-SoVITS v4 的 variance adaptor。为什么不重训底座？底座已具备高质量音色复刻，重训既贵又破坏角色一致性；Adapter 只在韵律子空间微调，音色保真与情感可控互不干扰，推理时彻底切断对 LLM 的依赖。

模块如何串联：完整 Pipeline

Data Flow
Training (Offline) Script Lines → LLM Rationale → VAD Targets → Adapter Learns Mapping Inference (Online, no LLM) Text → P2P Adapter → Prosody Embedding → GPT-SoVITS → Expressive Speech

核心思路 · 给面试官的直觉解释

一句话：把 LLM 的"思考"预先烤进权重。训练时 Qwen2.5-14B 像一位老戏骨示范"这句应该怎么演"，把示范结果浓缩成 VAD 三维数字 + 韵律标量；推理时只剩一个 11.8M 的学生 Adapter，完全不调用 LLM，实测 RTF 0.18（RTX 4090 FP16，约 180ms 合成 1s 音频）。这种"教师重、学生轻"的解耦，本质上是把推理时延复杂度从 O(LLM) 降到 O(Adapter)，同时保留了 LLM 的语义解释能力。

主要贡献
01
提出"离线蒸馏 + 在线推理"的两阶段解耦框架，把 LLM 的情感能力卸载到训练侧。
02
设计 LLM 情感蒸馏机制：让大模型先写"理由"，再产出 VAD 三维韵律目标。
03
轻量 P2P Adapter：在 GPT-SoVITS 上做角色一致的实时韵律控制。

PAPER · 02 IEEE TCE 作者 图像合成

多元特征引导的高频保真红外图像合成 Multivariate Feature-Guided Infrared Image Synthesis with High-Frequency Fidelity

研究背景

红外（IR）相机昂贵、采集成本高、数据稀缺，严重制约下游夜视、安防、行人检测算法的训练。

"用 RGB 合成 IR"是缓解这一瓶颈的关键手段，但现有方法常常丢失高频细节，并破坏热物理一致性 —— 看起来像热图，物理上却讲不通。

核心动机

能不能把"频域、空域、边缘"几条线一起喂给生成器，让 RGB → IR 的色彩重映射既细节锋利、又保持热分布的物理合理性？

方法 · 四元并行特征融合 + 自适应色彩重映射

填补的研究缺口

RGB → IR 跨模态合成的真正难点在于"一个特征空间装不下两类信息"：热分布是低频的大块全局统计量（哪一片热、哪一片冷），而边缘锐度与物体几何是高频的局部细节。以往单分支 GAN（Pix2Pix、CycleGAN）共用一条编码-解码路径，要么红外图过糊（细节丢失），要么热区错位（全局物理性破坏），二者只能取其一。

提出的新范式

用 Transformer 编解码器(STE-Net) + 多元特征分工，而非 GAN：论文明确弃用对抗学习——理由是自注意力能建模长程依赖、确定性输出更适合 ADAS 安全场景、且规避 GAN 的 mode collapse 与训练不稳。用四个解耦的频率/空间分支（Fourier / Spatial / Wavelet / Boundary）同时提特征，每个分支负责一种"物理量"，再用四元数卷积把它们融合，最后通过专门的颜色重映射模块(CRM)完成 RGB → IR 转换。本质是把"一个生成器做所有事"拆成"四个专家 + 一次代数融合"。

创新模块逐一拆解

① Fourier 分支对全图做傅里叶变换提取频谱特征，配合 MDTA（来自 Restormer 的通道维全局注意力）捕捉全局热分布——红外热图本质上是低频能量分布图，傅里叶域是它最自然的表征空间。没有这条分支，模型很难学到"整面墙比整张脸更热"的统计先验。
② Wavelet 分支小波分解给出多尺度高低频系数，同样接 MDTA，专门解决"既要保留窗框这种锐边、又要保留墙面这种缓变"的多尺度共存问题。傅里叶是全局的，小波在空间-频率联合域取折中。
③ Spatial 分支空域特征 + MDTA，维持像素级空间对应，保证 RGB 上的物体位置在 IR 输出里不会平移漂移。这是几何一致性的兜底分支。
④ Boundary 分支（Sobel）Sobel 派生的显式边缘特征注入。为什么这条分支不接 MDTA？Sobel 是 3×3 局部算子，全局注意力反而会把边缘模糊掉。它在后续四元数融合中充当实部（结构骨架），专治红外重建的"糊一团"通病——热成像里物体边缘往往是温差最大处。
⑤ CRM · 颜色重映射模块基于隐式神经表示的 MLP：f 把可见光 3 通道映到 128 维隐空间 Z，g 再映到红外单通道，每个子网 3 层全连接 + ReLU + 残差。为什么需要独立模块？RGB 与 IR 色域是非平凡非线性关系（黑衣可能很热、白色金属可能很冷），简单通道平均会彻底丢掉这种语义；CRM 把这一映射显式参数化、可学习。
⑥ MFFM · 多元特征融合（四元数卷积）把四路特征用四元数卷积融合：边界作实部、Fourier/Spatial/Wavelet 作虚部 i,j,k，经 Hamilton 积耦合。为什么用四元数而不是简单拼接/注意力？四元数代数天然建模四个分量之间的耦合关系，且参数极省（仅约 195K）；消融显示它优于 Concat / Grouped / Attention 融合。MFFM 放在 bottleneck，对原图全分辨率提取频域+边界后再与深层语义融合，补偿下采样丢失的高频。

模块如何串联：完整 Pipeline

Data Flow
RGB Image → STE-Net Encoder → 4 Branches (Fourier/Spatial/Wavelet/Boundary) → MFFM 四元数融合 → CRM 颜色重映射 → Decoder (无判别器/无对抗) → Synthetic IR

核心思路 · 给面试官的直觉解释

一句话：不同物理量用不同基底表征，再用四元数代数把它们耦合起来。傅里叶看全局热场，小波看多尺度纹理，空间看几何对应，边缘（实部）看锐度，CRM 学色域映射。损失只用 Smooth L1 + SSIM + LPIPS 等权相加（无对抗损失、无显式频域损失），靠 MFFM 在结构上注入高频。注意：RGB→IR 是跨模态映射、不存在像素级一一对应，所以 PSNR 绝对值天然偏低（≈14），真正能说明问题的是高频保真指标与下游行人检测 mAP 的领先。

主要贡献
01
提出 STE-Net：用 Transformer 编解码器 + 多元特征分工替代 GAN，规避对抗训练不稳与 mode collapse。
02
设计 CRM 基于隐式神经表示的颜色重映射，处理 RGB → IR 的非线性色域转换。
03
提出 MFFM 多元特征融合（四元数卷积，仅约 195K 参数），耦合 Fourier/Spatial/Wavelet/Boundary 四路特征。
实验结果
0
高频指标 AG（真实 IR 为 6.72，最接近）
0
SSIM（跨模态合成，绝对值偏低属正常）
0
下游 YOLOv5s 行人检测 mAP@50
0ms
推理延迟（26.83M 参数，单卡 V100）
网络总体架构：STE-Net 编解码器 + 四路特征 + MFFM/CRM。
定性对比图：与 CycleGAN、Pix2Pix、VQ-InfraTrans、DiffV2IR 等基线对照。

PAPER · 03 CGI 2026 第一作者 3D Gaussian Splatting

VEDAL：基于变分误差驱动异步学习的 3D 高斯分溅高效剪枝 VEDAL: Variational Error-Driven Asynchronous Learning for Efficient 3D Gaussian Splatting Pruning

研究背景

3D Gaussian Splatting（3DGS）虽然把神经辐射场拉到了实时渲染，但代价是要存几百万个高斯体，模型大、显存高，根本上不了手机、AR/VR 头显这种边缘设备。

以往的剪枝多采用"按梯度或不透明度排序、一刀切"的硬阈值策略，要么剪不动，要么剪过头导致渲染崩坏。

核心动机

能不能把"该不该剪掉这个高斯"建模为一个概率推断问题，让每个高斯独立地、带不确定性地做出自己的决定？

方法 · 变分误差驱动的异步剪枝

填补的研究缺口

现有 3DGS 剪枝方法（如按梯度幅值、不透明度、贡献度排序后硬阈值砍掉）有两个根本缺陷：第一，剪枝决策不可逆——一旦砍错就再也救不回来；第二，缺乏理论保证，砍多少全靠手工调参；第三，所有高斯被迫在同一时刻、同一标准下被裁决，无法因 Gaussian 而异地决定其留存概率。

提出的新范式

把剪枝形式化为变分推断：每个 Gaussian 是否保留是一个潜变量 z_i ∈ {0,1}，对其后验做变分近似。整个剪枝过程不再是离散的"砍/留"二选一，而是连续的概率优化——通过最小化变分自由能（重建误差 + KL 正则）端到端学习，每个 Gaussian 独立、异步地收敛到自己的保留概率。

创新模块逐一拆解

① 收敛条件变分推断把每个高斯"保留/剪枝"建为二值隐变量 z_i ∈ {0,1}，优化 ELBO（重构项 + KL 复杂度项）。为什么变分？离散硬剪不可逆、不可学；用变分后验 q(z_i) 把决策变成连续概率优化，可端到端反传，且 KL 项天然提供稀疏先验。关键是只对"已收敛"的高斯集合 A(t) 计算 KL，未收敛者不参与剪枝裁决。
② 预测误差门（Prediction-Error Gate）维护每个高斯 leave-one-out 重要性的 EMA（ρ=0.99），用自适应分位阈值 τ(t) 判断该高斯是否"收敛到可被裁决"。这就是"误差驱动"——门控信号来自每个高斯对重构误差的真实贡献，而非梯度幅值或不透明度这类启发式代理。为省算力，用 tile 光栅器缓存的 cᵢαᵢTᵢ 做一阶近似，每 100 迭代刷新，约 3% 开销。
③ 变分不确定性头 + 异步门一个极轻量 MLP（2 层 ×64，约 5K 参数）输出每个高斯的保留概率 αᵢ，用 Binary Concrete 松弛使其可微。"异步"体现在：各高斯按各自收敛时刻分别激活剪枝资格，而非同步批量删——纹理区收敛快、镜面/遮挡区收敛慢，异步避免过早剪掉尚未收敛的高斯造成的"误判级联"。Proposition 1 给出最优保留概率闭式解 αᵢ*=σ(Δᵢ/λ_KL + log(α/(1−α)))。

模块如何串联：完整 Pipeline

Data Flow
3DGS Init → + 不确定性头 (per Gaussian) → Render Loss + KL + Sparse → 预测误差门 (EMA) → 收敛即激活 → 异步剪枝 → Remaining Gaussians (5.2×) → （可选）FlexGaussian 属性量化 → Compressed Scene

核心思路 · 给面试官的直觉解释

VEDAL 的卖点不是"剪枝还能提质"，而是"用极小的质量代价换巨大的体积压缩"。在 Mip-NeRF360 上，高斯数从 3.25M 砍到 0.63M（5.2× 压缩，734MB→141MB），PSNR 仅从 27.48 降 0.31 dB 到 27.17，渲染反而从 148 提到 185 FPS。为什么质量损失这么小？因为变分框架 + 异步门只剪那些真正对渲染贡献小、且已经收敛的高斯——同步硬剪会误伤尚未收敛的高斯导致崩坏，而异步"等它收敛再裁决"避免了这种误判级联。VEDAL 本身只减高斯数量、不做属性量化；若再叠加正交的 FlexGaussian 量化，总压缩可达 27.2×（27MB）。

主要贡献
01
把剪枝形式化为收敛条件变分推断（ELBO），用概率隐变量 + Proposition 1 闭式解替代硬阈值。
02
提出预测误差门 + 异步门控：各高斯按各自收敛时刻分别裁决，避免同步剪枝的误判级联。
03
仅减少高斯数量即获 5.2× 压缩、质量损失 <0.31 dB；与正交的属性量化(FlexGaussian)组合可达 27.2×。

PAPER · 05 AAAI 2027 第一作者 多模态安全

NeuroGuard：面向多模态大模型安全的跨模态绑定异常检测 NeuroGuard: Cross-Modal Binding Anomaly Detection for Multimodal LLM Safety

研究背景

多模态大模型（MLLM）出现了一类新型攻击：图像安全、文字安全，但两者绑在一起就变成了不安全内容。传统单模态护栏面对这种"组合即攻击"几乎是无效的。

同时，给每个请求都跑一遍重型分类器既慢又贵，对在线服务不可接受。

核心动机

能不能不动 MLLM 主体，只在它跨模态绑定的瞬间"听一下"内部信号，就实时检出组合风险？

4D 高斯泼溅（4DGS）在 3DGS 基础上加入时间维度，能高保真重建动态场景，但代价是存储爆炸：一段动态场景往往是数百万个高斯 × 随时间变化的属性，动辄数 GB，难以传输、存储和在消费电子终端上回放。

已有的高斯压缩方法大多针对静态 3DGS，没有专门利用动态场景在时间维度上的强冗余，压缩比有限。

核心动机

动态高斯场景里，相邻时刻、相邻空间的高斯属性高度相似——这种冗余能不能用一个学习到的低维潜空间直接吃掉，让原本数 GB 的 4DGS 压到几百 KB，还能解码回可渲染的高斯？

方法 · 基于 VAE 的 4DGS 潜空间编解码器

填补的研究缺口

动态场景重建里，4DGS 的存储开销是落地最大的拦路虎：每个高斯不仅有位置/旋转/缩放/不透明度/球谐颜色，还要叠加随时间变化的运动/形变参数，规模随时间线性膨胀。现有压缩工作主要服务静态 3DGS（剪枝、量化、码本），把它们逐帧套到 4DGS 上既忽略了时序冗余，也难以达到动态场景传输所需的极致压缩比。

提出的新范式

"把 4DGS 当数据，用 VAE 学一个紧致潜表示来当编解码器"：不再逐属性手工量化，而是训练一个变分自编码器，把整套时变高斯属性映射进一个低维潜空间 z，存储/传输时只保留压缩后的潜码，渲染时由解码器重建出可直接泼溅的高斯。借助 VAE 学到的连续流形 + 潜码量化，实现最高 21900× 的压缩比。

创新模块逐一拆解

① 4DGS 属性的可压缩重组把每个高斯随时间变化的属性（位置、旋转、缩放、不透明度、球谐颜色 + 时序形变项）结构化组织成 VAE 可以吞入的张量形式。为什么这一步关键？动态高斯的属性维度异质、量纲差别大，直接喂给网络会让重建误差被某几个分量主导；先做归一化与结构化重组，VAE 才能在所有属性上均衡地学习紧致表示。
② 变分潜空间编解码编码器把高维高斯属性压到低维潜变量 z，解码器再重建出可渲染高斯；训练目标是重建保真 + KL 正则的标准 VAE 形式。为什么用 VAE 而不是直接量化？VAE 学到的是一个连续、规整的潜流形，相近的动态内容在潜空间里聚拢，天然把时序与空间冗余压进少量潜维度——这正是极致压缩比的来源，也比逐属性硬量化更抗失真。
③ 潜码量化与极致压缩对潜码做量化 + 紧凑编码，把 VAE 已经压缩过的潜表示进一步无冗余地落盘。压缩-保真权衡：真正决定最终压缩比的不是单看 VAE 维度，而是"潜空间维度 + 潜码量化精度"的组合，21900× 是在可接受重建质量下逼出来的极致点。

模块如何串联：完整 Pipeline

编解码流程
4DGS 动态高斯场景（数 GB） → 属性结构化重组 → VAE Encoder → 潜变量 z → 潜码量化 + 紧凑编码（潜表示落盘） → VAE Decoder 重建高斯 → 可泼溅渲染（最高 21900× 压缩）

核心思路 · 给面试官的直觉解释

"动态高斯里大部分信息是重复的，VAE 负责只记住不重复的那一点点。" 一段动态场景在相邻时刻、相邻空间上的高斯几乎雷同，逐属性存储等于把同样的信息抄了千百遍。VAE 把这套数据投影到一个低维潜流形上，相似内容在潜空间里挤到一起，于是只需存一个很小的潜码 + 解码器，就能在渲染时把整套高斯"长"回来。这就是为什么能从数 GB 压到几百 KB（21900×）——压缩的不是像素，而是动态高斯背后的低维结构。

LLM & Alignment 大模型与偏好对齐
LLMLarge Language Model
大语言模型，像 GPT、Qwen 这类用海量文本训练、能理解和生成语言的神经网络。本站多篇论文要么用它（蒸馏、规划、推理），要么评估/守护它。
SFTSupervised Fine-Tuning
监督微调，拿"问题→标准答案"的成对数据直接教模型模仿。优点简单，缺点是只学会"照着抄"，学不到"为什么这么答更好"。
RLHFRL from Human Feedback
基于人类反馈的强化学习。让人对模型的多个回答打分排序，再用这些偏好信号把模型"调教"得更符合人类喜好——ChatGPT 变好用的核心技术。
DPODirect Preference Optimization 直接偏好优化
理解它要先看 RLHF 的麻烦：RLHF 得先单独训一个奖励模型给回答打分，再用 PPO 这类强化学习去最大化奖励——两阶段、要在线采样、要调一堆超参，训练既慢又容易崩。DPO 的洞见是：奖励模型其实可以不显式存在。它用一段数学推导证明，"最大化奖励 + 不偏离原模型太远"这个 RLHF 目标可以等价改写成一个关于成对数据的分类损失——也就是只要喂"好回答 y⁺ vs 坏回答 y⁻"的偏好对，让模型把 y⁺ 的相对概率拉高即可，损失里已经隐含了奖励，无需训练独立奖励模型、也无需在线采样。代价是它仍然需要一个冻结的参考模型（原始 SFT 模型）当锚点防跑偏，所以训练时显存里要同时放两个模型。一句话：DPO 把 RLHF 的两阶段强化学习压成了一步监督式的偏好分类，更稳、更省、更好复现，是后续 SimPO、Progressive-SimPO 的共同起点。
偏好对Preference Pair
一组"被偏好的回答 y⁺ vs 被拒绝的回答 y⁻"。对齐训练的基本食材，告诉模型"这个比那个好"。
Bradley-Terry 模型BT Model
一个把"A 比 B 好多少分"换算成"A 胜过 B 的概率"的经典统计模型，公式是 σ(分差)。几乎所有偏好对齐方法的概率基础。
γ-margin奖励间隔
在偏好概率里强行要求"好回答必须比坏回答领先 γ 分以上"才算赢，逼模型把"专业咨询"和"通用废话"的差距拉大，区分更干脆。
Credit Assignment信用分配问题
"一段对话整体不错，到底是哪一句的功劳？"——多轮对齐的核心难题。整段一起算会把好句子的功劳摊薄、把坏句子罚过头。
梯度扩散 / 失衡Gradient Diffusion
把多轮对话当一个样本时，反向传播的学习信号被均匀摊到每一轮，关键好行为被稀释、坏行为又被过度惩罚，导致学不到细粒度策略。
MCTSMonte Carlo Tree Search
蒙特卡洛树搜索。像下棋时"在脑中推演几步再落子"：把可能的选择展开成一棵树，多次模拟后挑最优分支。AlphaGo 的核心算法之一。
Best-of-N (BON)N 选一采样
让模型生成 N 个候选，挑最好的那个。最朴素的"加搜索"基线。CUDA-Eval 用它当尺子，衡量更复杂的搜索策略到底有没有真增益。
CoTChain-of-Thought 思维链
让模型把"解题步骤一步步写出来"而非直接给答案。ATRIE 让 LLM 先写情感推理链，再蒸馏成韵律目标。
知识蒸馏Knowledge Distillation
用一个大"老师模型"教一个小"学生模型"，把大模型的能力压进小模型。ATRIE 把 14B 的情感推理蒸馏进 11.8M 的轻量 Adapter。
Adapter适配器
挂在大模型旁边的小插件，只训这一小块、冻住底座。既省算力又不破坏原模型能力。ATRIE 的 P2P 就是个韵律控制 Adapter。
Tokenizer分词器
把文字切成模型能吃的"词元(token)"的工具。不同模型族分词方式不同——CUDA-Eval 特地跨模型族复现，证明结论不是某个分词器的特例。
Generative & Representation 生成模型与特征表示
GANGenerative Adversarial Network
生成对抗网络：一个"造假者"和一个"鉴别者"互相博弈，逼造假者越来越逼真。强大但训练不稳。TCE 红外论文特地弃用它。
Mode Collapse模式坍塌
GAN 的常见病：生成器偷懒，只会产出几种样子、丧失多样性。用 Transformer 确定性输出可规避。
VAEVariational Autoencoder 变分自编码器
把高维数据压进一个规整连续的低维潜空间、再解码还原的网络。Latent4D 用它把数 GB 的 4D 高斯压到几百 KB。
潜空间 / 潜变量Latent Space / Variable
数据被压缩后所在的低维抽象空间，里面每个点(潜变量 z)对应一个还原结果。相似内容在潜空间里会挤到一起，这正是压缩的来源。
变分推断Variational Inference
当真实概率分布算不出来时，用一个简单分布去逼近它的数学手段。VEDAL 把"该不该剪掉这个高斯"建模成变分推断问题。
ELBOEvidence Lower Bound 证据下界
变分推断/VAE 的训练目标，由"重建保真 + KL 正则"两项组成，最大化它就等于让近似分布贴近真实分布。
KL 正则KL Divergence
衡量两个概率分布"差多远"的指标。当作正则项可约束潜空间别太放飞、保持紧凑，是 ELBO 里的复杂度惩罚项。
后验Posterior
"看到数据之后"对某个变量的概率判断。VEDAL 对每个高斯"保留与否"的后验做变分近似。
Binary Concrete二值松弛
把"留/剪"这种非0即1的硬选择变成可微的连续概率，好让梯度能传回去训练。VEDAL 靠它让离散剪枝决策变得可学。
隐式神经表示Implicit Neural Representation
不用查表、而是用一个小神经网络当函数来表示映射关系（如颜色坐标→数值）。TCE 的 CRM 用它学 RGB→红外的非线性色域映射。
自注意力Self-Attention
Transformer 的核心，让序列里每个元素都能"看遍全局其他元素"并按相关性加权。擅长建模长程依赖。
Cross-Attention交叉注意力
让一种信息"查询"另一种信息（如文本查图像）。ATRIE 的 Adapter 用它把语义对齐到韵律。
傅里叶变换Fourier Transform
把图像从"空间"换算到"频率"视角，看的是整体能量分布。红外热图本质是低频能量图，所以傅里叶域最自然。
小波分解Wavelet Transform
介于空间和频率之间的"多尺度放大镜"，能同时保留锐边和缓变。TCE 用它兼顾窗框锐边与墙面渐变。
四元数卷积 / MFFMQuaternion Convolution · 我在 TCE 红外论文的融合核心
四元数是"一个实部 + 三个虚部 i,j,k"打包成一组的超复数。我用它来做红外合成里的多元特征融合（MFFM 模块），解决的问题是：RGB→IR 要同时照顾四种异质信息——全局热场（Fourier 分支）、多尺度纹理（Wavelet 分支）、几何对应（Spatial 分支）、边缘锐度（Boundary 分支）。普通做法是把四路特征Concat 拼起来再卷积，但拼接只是"摆在一起"，各路之间没有显式的相互作用建模。四元数卷积的精妙在于：把边界特征当实部、Fourier/Spatial/Wavelet 当三个虚部 i,j,k，做卷积时走的是Hamilton 积（四元数乘法）——它的代数规则会让四个分量两两交叉相乘、强制耦合，等于在数学层面逼着"边缘锐度去校正热场分布、纹理去约束几何"，而不是各管各的。还有一个工程红利：四元数卷积权重在四个分量间共享，所以参数量极省（整个 MFFM 仅约 195K）。消融证据很硬：它优于 Concat / Grouped / Attention 等所有对照融合方式。位置上放在编解码器 bottleneck，对原图全分辨率提取频域+边界后再与深层语义融合，专门补偿下采样丢掉的高频。
Hamilton 积四元数乘法
四元数之间的乘法规则，会让四个分量相互交叉影响——这正是四元数卷积能耦合多路特征的数学原因。
Sobel 算子Sobel Operator
一个 3×3 的经典边缘检测小窗口，专挑亮度突变处。红外里物体边缘往往是温差最大处，Sobel 充当结构骨架。
MDTARestormer 通道注意力
来自 Restormer 的一种在通道维度做全局注意力的模块，省算力又能抓全局。TCE 的傅里叶/小波/空间分支都接它。
3D / 4D Vision 三维与动态场景重建
NeRFNeural Radiance Field 神经辐射场
用一个神经网络隐式表示整个 3D 场景、能从任意视角渲染的技术。效果惊艳但渲染慢，催生了后来的高斯泼溅。
3DGS3D Gaussian Splatting
用几百万个三维"高斯椭球"显式表示场景，能实时渲染、画质高。代价是模型巨大、上不了手机。VEDAL 给它瘦身。
4DGS4D Gaussian Splatting
在 3DGS 上加时间维度，能重建会动的场景。存储更爆炸(随时间线性膨胀)。Latent4D 专门压它。
高斯泼溅Splatting
把一个个高斯椭球"啪地拍到屏幕上"叠加成图像的渲染方式，比 NeRF 的逐光线积分快得多。
球谐颜色Spherical Harmonics
用一组球面基函数表示"同一个点从不同方向看颜色不同"(高光、反射)。是高斯属性里占空间的大头之一。
不透明度Opacity
每个高斯有多"实"——接近 0 就几乎透明、对画面贡献小。早期剪枝就爱按它一刀切，但 VEDAL 指出这是粗糙的启发式代理。
剪枝Pruning
删掉模型里不重要的部分(这里指删高斯)来减体积。难点是"砍错就救不回来"，VEDAL 用概率框架让它可逆可学。
时序冗余Temporal Redundancy
动态场景里相邻时刻几乎雷同的重复信息。逐帧硬存等于把同样内容抄千百遍，Latent4D 用 VAE 把它吃掉。
码本Codebook
一本"常用模式字典"，存原始数据时只记字典编号而非完整值，达到压缩。传统高斯压缩常用，Latent4D 改用 VAE 潜码。
Compression & Efficiency 模型压缩与高效推理
量化Quantization
把模型里的高精度浮点数压成低位宽整数(如 32-bit→8-bit/4-bit/1-bit)，省显存、提速度。代价是可能掉精度。
W1A1 / W2A8权重位宽/激活位宽
"W"是权重、"A"是激活的位数。W1A1=权重和激活都 1-bit(全二值，最激进)；W2A8=权重 2-bit/激活 8-bit(更温和的折中)。
XNOR + popcount位运算加速
二值网络的提速魔法：把浮点乘加换成按位异或同或(XNOR) + 数 1 的个数(popcount)，一次访存并行处理整字宽。这是二值化省算力的物理来源。
STEStraight-Through Estimator
直通估计器。二值化的 sign 函数没法求导，STE 让前向走二值、反向时假装它可导把梯度直接放行，使二值网络能训练。
SPD-ConvSpace-to-Depth Conv 无损下采样
Forestpest-YOLO 用它替代 stride 卷积：普通下采样直接丢掉 3/4 像素，对几十像素的小虫子是灾难；SPD-Conv 把空间像素搬到通道维，一个不丢。
EMAExponential Moving Average 指数滑动平均
一种"新值占小权重、历史占大权重"的平滑统计，抗抖动。VEDAL 用 EMA(ρ=0.99) 追踪每个高斯的重要性。
FP16 / FP32半/单精度浮点
16-bit / 32-bit 浮点数。FP16 更快更省但精度低。CUDA-Eval 发现大量失败正是模型没处理好 fp16/fp32 的精度语义。
Robotics & Navigation 机器人与具身导航
SLAMSimultaneous Localization and Mapping
同步定位与建图：机器人一边搞清自己在哪、一边画出环境地图。室内导航的地基。
语义 SLAMSemantic SLAM
在 SLAM 基础上给地图贴上"这是书架/那是墙"的语义标签。DOGe 用多模态语义 SLAM 在重复纹理走廊里不迷路。
RGB-D / LiDAR深度相机 / 激光雷达
RGB-D=彩色图+每像素深度；LiDAR=用激光测距出点云。两者给机器人几何感知。4D LiDAR 还带时间维度。
log-odds对数几率
把概率换算成"对数赔率"，好处是多次观测可以直接相加融合。语义建图用它把多帧观测累积成一张可靠的语义地图。
Detection / Network Modules 检测分割与网络模块
YOLOYou Only Look Once
最流行的实时目标检测框架，一次前向就框出所有物体。Forestpest-YOLO 在它基础上做林业小目标改造。
CSPOK跨阶段全方位核块 · 我在 Forestpest-YOLO 提出的模块
林业害虫检测有个特异难点：害虫的判别特征是局部细纹理（毛、足、翅纹），而它周围的叶片/树枝纹理跟它高度相似（保护色），单一感受野根本分不清"这是虫还是叶子的一小块"。CSPOK 就是为此设计的：①跨阶段（Cross-Stage）——借鉴 CSP 结构把特征分流，一部分走深层变换、一部分作 shortcut 直连，最后再融合，既保留浅层细节又叠加深层语义，还省算力；②全方位核（Omni-Kernel）——同时用大核和小核多个尺度去看同一块区域，小核抓虫体本身的精细纹理、大核看周边上下文，让模型能在"局部 vs 上下文"两个尺度上对比，把"虫纹理"从"相似的叶纹理"里区分出来，同时对背景噪声做抑制。直觉就是：要判断一小块毛刺是不是虫子，光盯着这一小块不够，还得看它周围的大环境——CSPOK 把这两个视角拼进同一个块里。它和 SPD-Conv（无损下采样、不丢小目标像素）、VarifocalLoss（按 IoU 给高质量样本加权）一起，构成 Forestpest-YOLO 应对"小目标+遮挡+类背景相似"的三件套。
VarifocalLoss变焦损失
训练时按 IoU 给样本加权，让定位准的高质量样本贡献更大梯度。比一视同仁的 Focal Loss 更适合小目标精细定位。
Focal Loss焦点损失
经典检测损失，降低大量简单负样本的权重、聚焦难例。VarifocalLoss 是它的进化版。
VADValence-Arousal-Dominance
心理学的三维情感空间：愉悦度/唤醒度/支配感。比离散标签(开心/生气)能连续插值。ATRIE 把情感推理落到 VAD 当韵律目标。
Multimodal Safety 多模态安全(NeuroGuard)
MLLMMultimodal LLM 多模态大模型
能同时处理图像+文本的大模型。强大但带来新型安全风险——单模态护栏管不住。
跨模态绑定攻击Cross-Modal Binding Attack
NeuroGuard 针对的攻击：图安全、文也安全，但绑一起就越界(如"如何做蛋糕"配化学武器示意图)。单看每项都良性，组合才触发越狱。
越狱Jailbreak
用巧妙输入绕过模型的安全限制、诱导它输出有害内容。SIUO、FigStep 都是越狱攻击基准。
护栏Guardrail
挡在模型输入/输出处的安全过滤器。传统护栏只看单模态、且重型分类器慢；NeuroGuard 做超低延迟、模型无关的版本。
EffRank / 谱熵Effective Rank · NeuroGuard L1 探针
这是 NeuroGuard 第一层（L1）用的复杂度探针。"有效秩"回答的是"一个表征实际上'摊开'在多少个维度上"——一个矩阵名义上可能有几百维，但如果信息都挤在少数几个方向，它的有效维度就很低。算法上：对表征做奇异值分解，把奇异值归一化成一个概率分布，再算这个分布的谱熵（spectral entropy），熵越高说明能量越均匀地铺在各维度上、有效秩越大、表征越"复杂/丰富"；熵越低说明信息越集中、维度越坍缩。NeuroGuard 在共享投影后用它估计图文融合表征的复杂度，作为 7 维证据向量里的一路信号——因为正常的良性图文绑定和被攻击的异常绑定，在"表征复杂度坍不坍缩"上会有可分的差异。它和 MAC/dPLV（方向性）、CDS（时间漂移）互补：EffRank 看结构复杂度，方向信号看绑定角度，CDS 看多轮累积，多路证据合起来才稳。
多模态对齐Multimodal Alignment / Cross-Modal Binding
指 MLLM 把图像和文本两种模态映射到同一个语义空间、并把它们"绑"在一起理解的过程——比如让"一张猫的照片"和"猫"这个词在模型内部指向同一个概念。这是所有多模态大模型工作的底层机制，也是 NeuroGuard 整篇论文的立论根基：正因为 MLLM 会在某些关键中间层把图文做跨模态绑定（cross-modal binding），跨模态绑定攻击才有机可乘——攻击者让单看安全的图、单看安全的文，在绑定的那一刻组合成不安全语义（如"如何制作蛋糕"配化学武器示意图）。传统单模态护栏只在对齐之前分别审图、审文，自然抓不到这种"绑定即攻击"。NeuroGuard 的切入点正是对准"对齐/绑定"发生的那一层去监听：冻结 MLLM 当免费特征提取器，取 post-fusion（融合后）隐层表征，用 EffRank/dPLV/MAC/CDS 几路探针判断这次跨模态绑定的模式是否偏离正常分布。换句话说，NeuroGuard 不审"内容"、只审"对齐方式"——这是它模型无关、超低延迟、且对组合攻击有效的根本原因。（注：对齐在不同语境有两义——这里指图文模态对齐；前面 DPO/SimPO 那类是偏好对齐，让模型行为符合人类偏好，别混淆。）
GRUGated Recurrent Unit
一种轻量循环神经网络，擅长处理时序、记住上下文。NeuroGuard 用 GRU 变体滤掉瞬时模态不一致造成的误报。
PLV / dPLV锁相值 / 投影锁相值 · dPLV 是我在 NeuroGuard 的改造
PLV（锁相值）本是神经科学/脑电分析里的经典量，衡量两个信号的相位是否长期同步——不管它们幅度大小，只看"步调一致不一致"，输出 0（完全不同步）到 1（完全锁相）。我把它借来检测图、文两路表征在跨模态绑定时的相位一致性，原因正是前面 MAC 说的洞察：组合攻击在幅度/相似度上伪装得很好，但相位/方向会露馅，PLV 这种"只看相位、不看幅度"的工具天生适合抓这种隐蔽偏差。dPLV（投影锁相值）是我做的关键改造：传统 PLV 在时间域沿时序算相位同步，但我面对的不是时间序列、而是高维隐层表征，于是把锁相的概念从时间域迁移到投影域——先把表征投影到特定方向上，再在投影空间度量图文绑定的角度一致性。这样既保留了 PLV"抗幅度伪装、专抓方向异常"的优点，又能直接作用在 MLLM 的隐状态上。dPLV 是 MAC（多尺度角度一致性）的底层度量原语。
MAC / CDS多尺度角度一致性 / 累积偏差分 · 我在 NeuroGuard 提出的核心信号
这两路是 NeuroGuard 能检出"跨模态绑定攻击"的真正杀手锏，理解它们要先抓住一个反直觉的关键洞察：SIUO/FigStep 这类组合攻击（图安全+文安全、绑一起才越界）在普通的图文相似度空间里根本藏得住——它们的图文不仅不"违和"，反而绑定得异常好（cos 相似度甚至偏高），所以靠"相似度异常"来检测会完全失效。必须换一个维度看：方向性。① MAC（多尺度角度一致性）：我把脑电分析里的锁相值 PLV从时间域搬到投影域（得到 dPLV），在多个尺度上度量图、文表征绑定时的角度/相位是否一致。组合攻击虽然在幅度（相似度）上伪装得很好，但它的绑定方向会和正常样本系统性地偏开——MAC 抓的就是这个露馅的方向信号。② CDS（累积偏差分）：针对多轮渐变越狱（一点点把对话往危险方向带、每一步都不明显），用 leaky 积分把每轮的微小偏差累加追踪——单看一轮发现不了，但漂移累积起来就会突破阈值。这俩配合 L1 的 EffRank、L2 的 GRU 滤波，最后只把 7 维证据喂给逻辑回归决策。它们也是 NeuroGuard 鲁棒性的来源：面对自适应 PGD 攻击，扁平 MLP 分类器会被沿少数方向绕过，而方向性+累积信号守得住。
PGD 攻击Projected Gradient Descent
最强的自适应对抗攻击之一，沿梯度反复微调输入绕过防御。NeuroGuard 的方向性+累积信号能扛住它，而扁平 MLP 分类器会被绕过。
逻辑回归Logistic Regression
最简单的二分类模型，画一条线分两类。NeuroGuard 在 7 维证据向量上用它做最终决策——前面已把高维语义浓缩成少数可解释统计量。
Experiment Methodology 实验方法学(CUDA-Eval)
CUDA / 核函数CUDA Kernel
CUDA 是英伟达 GPU 的并行编程框架，核函数(kernel)是在 GPU 上并行跑的那段代码。CUDA-Eval 研究 LLM 写核函数的能力。
SPCSearch-Proposal Compatibility · 我在 CUDA-Eval 提出的核心诊断量
CUDA-Eval 要回答"给 LLM 加一套搜索策略，到底有没有用、对谁有用"。业界惯常报"我的 Agent 比 baseline 加速 X×"，但那是把生成器、搜索器、评估器、容差、硬件全耦在一起的黑盒数字，分不清功劳归谁。SPC 把这件事量化干净：SPC = PR(π) − PR(BON)，即"某搜索控制器 π 的通过率"减去"Best-of-N 朴素基线的通过率"，单位是百分点，范围 [−100, +100] pp。它是一个边际贡献量（类似因果推断里的 ATE），只衡量"搜索这一个组件单独带来的增减"，因为分母 BON 已经把"多采样几次"的红利扣掉了。它揭示的核心结论是"搜索不是普适加成"：同一个 MCTS 控制器，在 Qwen2.5-7B-Instruct 上是 helpful（14.7% vs BON 6.7%），但在更弱的 Coder-1.5B 上随着搜索预算增大，SPC 会从 +40pp 一路翻转到 −40pp（搜索反而拖累）。据此把 (模型, 控制器) 组合分成三种 regime：controller-helpful（搜索真有用）、proposal-bound（瓶颈在生成器、搜索无力）、proposal-saturated（生成器已饱和、加搜索有害）。这把"该投资哪一环"从拍脑袋变成了可测量的决策。
因果推断 / ATECausal Inference / Average Treatment Effect
回答"是这个因素真的导致了结果吗"的统计学。ATE=某变量的平均处理效应。CUDA-Eval 把组件消融当因果实验做，量化每个组件的边际贡献。
全因子实验Full Factorial
把所有因素的所有组合都跑一遍(这里 4320 格)，才能干净地分离每个因素的影响。区别于"只调一个看一个"的粗糙比较。
数值失配Numerical Mismatch
代码编译通过、能跑，但算出来的数和参考答案差太多。CUDA-Eval 的核心发现：85.6-95% 的失败是这种、而非语法错——瓶颈在数值语义而非代码生成。
torch.allclose数值容差比对
PyTorch 判断两个张量"是否足够接近"的函数，靠相对容差 rtol 和绝对容差 atol 控制松紧。统一容差(rtol 1e-3/atol 1e-5)是公平横向比较的前提。
pass rate通过率
生成的核函数里编译通过且数值正确的比例。SPC 就是不同策略 pass rate 的差值。
warmup预热
正式计时前先空跑几次让 GPU 进入稳定状态，避免首次启动开销污染测速。CUDA-Eval 用 5 warmup + 20 次 CUDA-event 计时。
消融实验Ablation Study
逐个拿掉某个模块看性能掉多少，以此证明这个模块真有用。本站多篇论文都用消融验证各模块贡献。
Evaluation Metrics 常见评估指标
PSNR峰值信噪比
衡量重建图像与原图差多少，越高越好(dB)。注意跨模态合成(如 RGB→红外)无像素级对应，PSNR 天然偏低属正常。
SSIM结构相似性
比 PSNR 更贴近人眼地衡量结构相似程度(0-1，越高越像)。
LPIPS感知相似度
用神经网络特征衡量两图的感知差异，越低越像。比 PSNR/SSIM 更符合人类主观感受。
FPSFrames Per Second 帧率
每秒渲染/处理多少帧，越高越流畅。VEDAL 剪枝后渲染从 148 提到 185 FPS。
RTFReal-Time Factor 实时率
合成 1 秒音频要花多少秒，小于 1 才算实时。ATRIE 的 RTF 0.18(约 180ms 合成 1s 音频)。
UTMOS客观自然度评分
用模型自动预测语音的自然度 MOS 分(代替人工听感打分)。ATRIE 达 4.28(VITS 为 4.05)。
mAP / mAP@50平均精度均值
目标检测的综合精度指标。@50 指 IoU 阈值 0.5。越高越准。
IoUIntersection over Union 交并比
预测框和真实框重叠程度(交集/并集，0-1)。检测/分割判对错的基本尺子。
AUC / F1曲线下面积 / 调和均值
分类器质量指标：AUC 越接近 1 区分力越强；F1 是精确率和召回率的调和平均。NeuroGuard 多基准 AUC 近 1.0。
AG / EPI / HFER高频保真指标
衡量图像细节锐度/高频信息的指标(平均梯度等)。TCE 红外合成在这三项上最接近真实红外。
Fleiss κ多标注者一致性
衡量多个标注员意见一致程度的系数(0-1)。ATRIE 的情绪标注 κ=0.78 说明标注质量可靠。
